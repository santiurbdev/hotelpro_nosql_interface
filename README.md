# 🏨 HotelPro - NoSQL Database & Desktop Interface

## 🇺🇸 English Version

### 📖 Introduction
**HotelPro** is a comprehensive data management project that bridges the gap between a NoSQL database and a user-friendly desktop interface.

The core of this project is a **MongoDB** database designed for a hotel chain. It features **4 complex aggregation queries** (implemented in Python and executed via the UI) that generate real-time insights:
1. Revenue and reservations grouped by hotel and month.
2. Revenue generated by service type.
3. Total nights reserved by room type and base rate.
4. Business rule validations (check-in/check-out logic and room capacity).

All these queries are seamlessly integrated into a modern, responsive desktop interface built with **Python** and **CustomTkinter**, allowing users to interact with the data, search, and export reports to CSV effortlessly.

---

### 🛠️ Tools & Technologies Used
* **MongoDB & MongoDB Compass:** NoSQL database engine used for data storage, modeling, and exporting collections into JSON format.
* **PyCharm (Database Tools):** Integrated Development Environment connected directly to the local database instance (`localhost`) to write and test complex queries and aggregation pipelines (`find`, `aggregate`, `$lookup`, `$unwind`, `$match`).
* **CustomTkinter & Python:** Used to build the modern, dark/light-mode capable desktop interface.
* **Git & GitHub:** Version control and cloud repository hosting for database backups, query scripts, and source code.
* **AI-Assisted Development:** Modern AI tools were used as a programming assistant to structure the aggregation pipelines, refine the UI styling, and accelerate the development lifecycle, ensuring clean and efficient code.

## 🚀 How to Run the Project

> **Follow these steps to get a local copy up and running.**

### **1️⃣ Prerequisites**
* Ensure you have [MongoDB Community Server](https://www.mongodb.com/try/download/community) installed and running locally on `localhost:27017`.
* **Python 3.10** or higher installed.

### **2️⃣ Install Dependencies**
Open your terminal and run:

```bash
pip install customtkinter pymongo pillow tkcalendar

```
---

### **3️⃣ Restore the Database**

The project includes a folder named `db_hotelpro` with the JSON backups. Import them into MongoDB using your terminal:

```bash
# Import core collections (repeat for the rest if needed)
mongoimport --db hotel_pro --collection hotel --file db_hotelpro/hotel_pro.hotel.json --jsonArray
mongoimport --db hotel_pro --collection reserva --file db_hotelpro/hotel_pro.reserva.json --jsonArray
mongoimport --db hotel_pro --collection servicio --file db_hotelpro/hotel_pro.servicio.json --jsonArray
mongoimport --db hotel_pro --collection consumo_servicio --file db_hotelpro/hotel_pro.consumo_servicio.json --jsonArray
```
### **4️⃣ Run the App**

```bash
python db_hotelpro_interfaz.py
```

# 🏨 HotelPro - Base de Datos NoSQL e Interfaz de Escritorio

## 🇪🇸 Versión en Español

### 📖 Introducción
**HotelPro** es un proyecto integral de gestión de datos que conecta una base de datos NoSQL con una interfaz de escritorio intuitiva y fácil de usar.

El núcleo de este proyecto es una base de datos **MongoDB** diseñada para una cadena hotelera. Incluye **4 consultas complejas de agregación** (implementadas en Python y ejecutadas desde la interfaz) que generan información en tiempo real:
1. Ingresos y reservas agrupados por hotel y mes.
2. Ingresos generados por tipo de servicio.
3. Total de noches reservadas por tipo de habitación y tarifa base.
4. Validaciones de reglas de negocio (lógica de check-in/check-out y capacidad de las habitaciones).

Todas estas consultas están integradas de forma fluida en una interfaz de escritorio moderna y responsiva construida con **Python** y **CustomTkinter**, permitiendo a los usuarios interactuar con los datos, realizar búsquedas y exportar reportes a CSV sin esfuerzo.

---

### 🛠️ Herramientas y Tecnologías Utilizadas
- **MongoDB y MongoDB Compass:** Motor de base de datos NoSQL utilizado para el almacenamiento, modelado y exportación de colecciones en formato JSON.
- **PyCharm (Database Tools):** Entorno de desarrollo integrado conectado directamente a la instancia local de la base de datos (`localhost`) para escribir y probar consultas complejas y pipelines de agregación (`find`, `aggregate`, `$lookup`, `$unwind`, `$match`).
- **CustomTkinter y Python:** Utilizados para construir la interfaz de escritorio moderna con soporte para modo claro y oscuro.
- **Git y GitHub:** Control de versiones y alojamiento del repositorio en la nube para respaldos de la base de datos, scripts de consultas y código fuente.
- **Desarrollo Asistido por IA:** Se utilizaron herramientas modernas de inteligencia artificial como asistente de programación para estructurar los pipelines de agregación, refinar el estilo de la interfaz y acelerar el ciclo de desarrollo, garantizando un código limpio y eficiente.
